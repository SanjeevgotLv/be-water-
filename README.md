# 喝水提醒小工具 💧

一个轻量、直接打开就能用的喝水提醒小工具。  
它会根据你的体重、水杯大小、作息时间和一些生活状态，自动算出今天大概要喝多少水、分成几杯、什么时候提醒你喝。

## 它能做什么 ✨

- 根据体重估算每日饮水目标
- 按水杯容量换算今日杯数
- 根据起床和睡前时间生成喝水计划
- 支持活动量、炎热天气、咖啡/浓茶、重盐饮食等加量规则
- 可以记录一杯、撤销上一杯、重置今日记录
- 支持浏览器桌面提醒
- 今日进度会保存在浏览器本地

## 当前计算规则 🧮

基础目标：

```text
每日饮水量 = 体重 kg x 35 ml
```

额外加量：

```text
普通活动：+350 ml
运动较多：+700 ml
炎热/干燥：+450 ml
咖啡或浓茶：+250 ml
重盐饮食：+250 ml
```

最后会按 `50 ml` 取整，让数字看起来更舒服一点。

## 怎么打开 🚀

直接用浏览器打开：

```text
index.html
```

或者在当前目录启动一个本地服务器：

```bash
python -m http.server 5173
```

然后访问：

```text
http://127.0.0.1:5173
```

## 使用小贴士 🥤

- 杯子容量填你最常用的杯子，比如 `350ml`
- 如果今天运动、天气热、吃得比较咸，可以勾上对应规则
- 睡前 90 分钟少提醒默认开启，避免临睡前疯狂补水
- 点「记录一杯」就会更新进度和下一次建议时间
